Green

A triolet

Published in The Lark
So, how can we describe the colour ‘green’
In writing that invokes the inner eye,
When nothing of the image can be seen?
And how should we define the colour ‘green’
Code hex-a hash 3, 2, c, d, sixteen?
Or field and forest, meadow, leaf, and life?
Just how might we depict the colour ‘green’
In writing that invokes the inner eye?
